# design

- `ui kit`: guía de diseño para implementar en código (principios, tokens, componentes, patrones).
- `tokens.md`: todos los tokens del sistema en tablas (color, tipografía, espaciado, radios, sombras, movimiento) y los valores parecidos o en conflicto por decidir.
- `componentes.md`: cada componente del kit, su equivalente en shadcn/ui (o si se construye desde cero) y en qué pantallas aparece.
- `auditoria.md`: qué se tomó de cada referente visual.
- `flujos/`: pantallas exportadas de Figma, una carpeta por flujo.
- `Referencias img/`: imágenes de referencia visual.
